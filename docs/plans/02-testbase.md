ЗАДАЧА ФАЗЫ 1 — TestBase и конфигурация запуска. Никакого Allure, никаких новых тестов и PageObject.

ПРЕДУСЛОВИЯ
- Прочитай `docs/plans/decisions.md`: используй решения S1 (пакеты), S6 (навигация), S7 (жизненный цикл браузера), S12 (источник конфига).
- Если нужного решения нет — задай вопрос с дефолтом и обнови `decisions.md` до начала правок.

1. КОНФИГ
   - Реализуй источник конфигурации согласно S12 с приоритетом: system property → env → default.
   - Минимальный набор: `baseUrl` (default `https://github.com`), `browser` (chrome), `headless` (false), `browserSize` (1920x1080), `timeout` (10s), `remote` (пусто, для Jenkins/Grid).
   - Имена ключей сделай предсказуемыми и задокументируй в `decisions.md`: какие `-D`, какие env-переменные.
   - Не добавляй Owner/иные библиотеки без согласования.

2. TESTBASE
   - `@BeforeAll` (static) — применение конфигурации к Selenide: `Configuration.baseUrl`, `browser`, `headless`, `browserSize`, `timeout`, `remote` (если задан).
   - Навигация и закрытие браузера — строго по S6/S7. Если по S6 тест открывает страницу сам — не добавляй `open("/")` в `@BeforeEach`.
   - Не добавляй скриншоты/шаги Allure — это фаза 3.
   - Существующий `SearchTests` приведи к `TestBase` минимально: наследование/расширение по S7, URL — через `baseUrl` согласно S6. Локаторы и логику теста не меняй.

3. ПРОБРОС `-D` В TEST JVM (обязательно)
   - Gradle не передаёт `-D` из CLI в форк тестового JVM автоматически. Проверь это на практике и настрой `tasks.withType(Test)` так, чтобы нужные ключи доезжали (например только `selenide.*` и твои собственные `baseUrl`/`headless`/`browser`), без `System.getProperties()` целиком.
   - Проброс должен быть явным и читаемым: никаких «магических» копирований всех свойств.
   - Проверка: временно выведи фактические значения `Configuration.baseUrl`, `Configuration.headless`, `Configuration.browser` при старте, убедись в переопределении, затем убери отладочный вывод.

4. ПРОВЕРКИ (все — часть DoD)
   - `./gradlew test` — headed, зелёный.
   - `./gradlew test -Dselenide.headless=true` — зелёный, окно браузера реально не открывается.
   - `./gradlew test -DbaseUrl=<безопасный URL или тот же github>` — значение применяется (подтверди логом/поведением, затем убери лог).
   - Повторный запуск без `-D` возвращает дефолт (нет «залипания» свойства).

5. ОТЧЁТ
   - Файлы и `git diff --stat`.
   - Как переопределять конфиг: точные `-D` и env-имена (это попадёт в README и CI).
   - Что осталось на фазу 3 (Allure) и фазу 6 (remote/Grid).
   - Обнови `decisions.md`: фактические имена классов/пакетов, ключи конфигурации, статус фазы.

ОГРАНИЧЕНИЯ
- Не добавляй зависимости, кроме случаев, когда без них нельзя выполнить пункт 3, и только после согласования.
- Не трогай локаторы, ассерты и структуру теста сверх необходимого.
- Не коммить.

DoD ФАЗЫ
- Все четыре проверки из п.4 выполнены и описаны в отчёте.
- `decisions.md` содержит таблицу «ключ конфигурации → `-D` → env → default».
- Дифф затрагивает только TestBase, конфиг, `build.gradle` и минимальную правку `SearchTests`.
